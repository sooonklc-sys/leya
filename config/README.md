# Настройки запуска

- `server.json` — адрес и порт локального сервера: `127.0.0.1:8765`. Переменные окружения `HOST` и `PORT` переопределяют эти значения.
- `compose.yaml` — сборка и запуск приложения в Docker с доступом на `127.0.0.1:8765`.

Команды запуска приведены в [README проекта](../README.md) и [инструкции по развёртыванию](../docs/DEPLOYMENT.md).
