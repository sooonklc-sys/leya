# Проверка проекта

## Автоматические тесты

```sh
npm test
npm run build
```

`tests/core.test.mjs` проверяет правило Hb, пропуски, необязательный RDW, выбор модели, воздержание вне диапазонов, импорт CSV, заголовки и признаки дат Excel. `tests/server.test.mjs` запускает сервер на свободном порту и проверяет раздачу сайта, запрет POST и недоступность файлов вне `dist/`. `tests/demo.test.mjs` проверяет импорт синтетического набора и ожидаемые ветви расчёта.

GitHub Actions повторяет тесты и сборку, публикует автономный HTML как артефакт. Отдельное задание собирает и запускает Docker и проверяет HTTP-ответ. Отсутствие ошибок тестов не доказывает медицинскую эффективность.

## Проверка в браузере

1. Загрузить `examples/demo.csv`. Должны появиться три записи, у третьей RDW пуст.
2. Переключить запись, выполнить анализ и подготовить памятку.
3. Изменить анализ. Старая памятка должна сброситься.
4. Внести правку в памятку. Отметка проверки должна сняться.
5. Открыть печать и проверить текст пациента, комментарий и следующий шаг.
6. Повторить в `release/hemonavigator.html` с отключённой сетью.
7. Проверить узкий экран и реальное устройство для защиты.

Отдельно проверялся импорт XLSX со встроенными и пользовательскими форматами дат, ISO-датами, числовыми ячейками и посторонним столбцом даты. Даты в результатах отклоняются с адресом, дробные значения сохраняются. CSV-эвристика блокирует подозрительные серийные номера, но не гарантирует обнаружение всех возможных повреждений Excel.

Браузерные проверки выполнялись в Microsoft Edge. Отдельная проверка Safari/iOS и нативного WebMCP не выполнена. Проверка Docker на компьютере разработки недоступна из-за отсутствия Docker, результат запуска контейнера отслеживается в CI.
