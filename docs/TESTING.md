# Проверка проекта

## Автоматические тесты

```sh
npm test
npm run build
```

`tests/core.test.mjs` проверяет правило Hb, пропуски, необязательный RDW, выбор модели, воздержание вне диапазонов, импорт CSV, заголовки и признаки дат Excel. `tests/server.test.mjs` запускает сервер на свободном порту и проверяет раздачу сайта, запрет POST и недоступность файлов вне `dist/`. `tests/demo.test.mjs` проверяет импорт синтетического набора и ожидаемые ветви расчёта.

GitHub Actions повторяет тесты и сборку, публикует автономный HTML как артефакт. Отдельное задание собирает и запускает Docker и проверяет HTTP-ответ. Отсутствие ошибок тестов не доказывает медицинскую эффективность.

Дополнительно `tests/pdf.test.mjs` проверяет выбор столбца результата, десятичную запятую, переносы названий, продолжение таблицы, единицы, повторы, неравенства, пустые страницы и исключение идентификаторов. Фикстуры синтетические.

Проверка совместимости PDF с Safari: поток текста без `Symbol.asyncIterator` должен читаться через `getReader()` с сохранением порядка и координат. При ошибке чтения частичные данные не возвращаются, блокировка reader освобождается. Эти тесты воспроизводят отсутствие API; они не заменяют проверку на реальном Mac/iPhone.

## Проверка в браузере

1. Выбрать встроенный учебный пример либо загрузить поддерживаемый PDF без персональных данных.
2. Для PDF сверить строки, исправить число, проверить сброс отметки, подтвердить и перенести в форму. Указать возраст и пол, выполнить анализ и подготовить памятку.
3. Изменить анализ. Старая памятка должна сброситься.
4. Внести правку в памятку. Отметка проверки должна сняться.
5. Открыть печать и проверить текст пациента, комментарий и следующий шаг.
6. Повторить в `release/leya.html` с отключённой сетью.
7. Проверить узкий экран и реальное устройство для защиты.

Табличные функции сохранены для разработческих тестов; в текущем интерфейсе загрузки Excel/CSV нет. Ранее отдельно проверялся импорт XLSX со встроенными и пользовательскими форматами дат, ISO-датами, числовыми ячейками и посторонним столбцом даты. Даты в результатах отклоняются с адресом, дробные значения сохраняются. CSV-эвристика блокирует подозрительные серийные номера, но не гарантирует обнаружение всех возможных повреждений Excel.

Загрузка двухстраничного текстового PDF проверена локально в Microsoft Edge: 10 показателей, исправление и подтверждение, запрет Excel и повреждённых файлов, отмена, экран 390 пикселей и автономный HTML с отключённой сетью. Внешних запросов и отправки анализов при проверке не было. Исходный медицинский бланк в тестовые файлы репозитория не включён. Браузерные проверки выполнялись в Microsoft Edge. Отдельная проверка Safari/iOS и нативного WebMCP не выполнена. Проверка Docker на компьютере разработки недоступна из-за отсутствия Docker, результат запуска контейнера отслеживается в CI.
