# Презентация «Лея»

[PDF для просмотра](leya.pdf) · [Редактируемые слайды](leya.pptx)

Восемь слайдов для краткого технического представления проекта жюри. Презентация дополняет [демонстрацию за три минуты](../../DEMO.md). В PDF внешний вид зафиксирован. Для редактирования PPTX шрифты Manrope и Unbounded доступны с лицензиями в `dist/assets/`.

1. Лея: помощник врача и объяснение пациенту.
2. Задача: разные наборы анализов и неизвестные показатели.
3. Врач и пациент: сводка, проверка и памятка.
4. Ввод и контроль формата, включая ошибки Excel.
5. Логика и архитектура локального расчёта.
6. Метрики внутреннего теста на 210 записях.
7. Медицинские ограничения и обработка данных.
8. Демонстрация и дальнейшая проверка.

Источники: README, документация модулей и `model-evaluation.json`. Ссылки и пояснения включены в заметки PPTX. Использована иллюстрация проекта. Пациентских данных, вымышленных результатов клинических испытаний и обещаний юридического соответствия нет.
