## Перед сдачей

- Убедиться, что жюри получило доступ к закрытому репозиторию или архиву. Наличие ссылки само по себе не предоставляет права доступа.
- Проверить успешный статус тестов, сборки и контейнера в Actions.
- Скачать автономный HTML и презентацию заранее, открыть их на оборудовании для защиты.
- Уточнить у организатора порядок сдачи и допустимое оборудование. Репозиторий сам по себе не подтверждает соблюдение регламента мероприятия.

История разработки сохранена. Исходные пациентские данные в комплект не входят. Презентация описывает фактически реализованный MVP и внутренние метрики, не заявляя клиническую готовность.
