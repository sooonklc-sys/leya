# Разработка проекта

«Лея» — веб-сервис для скрининга лабораторных данных, разработанный в рамках хакатона. Проект включает подготовку данных, обучение моделей, ввод и импорт анализов, отчёт для врача и памятку пациенту.

## История изменений

В репозиторий загружена начальная версия MVP. Последующие изменения фиксируются отдельными коммитами. Для продолжения работы используйте свежий клон репозитория GitHub.

## Как продолжать работу

1. Создать ветку под конкретное изменение: `git switch -c feature/short-name`.
2. Внести изменение и выполнить `npm test`, затем `npm run build`.
3. Проверить изменённый сценарий в браузере; при изменениях модели отдельно пересчитать качество на отложенной выборке.
4. Посмотреть `git diff`, выбрать нужные файлы командой `git add`, сделать коммит с описанием реального изменения.
5. Отправить ветку в GitHub и открыть pull request для обсуждения.

Сценарий демонстрации описан в [DEMO.md](../DEMO.md). Автоматические проверки запускаются в GitHub Actions.

## Данные и воспроизведение

Исходные записи пациентов, бланки, словарь Excel и временные выгрузки не включены в репозиторий. Для повторного обучения нужен законно полученный исходный датасет и словарь организатора. В репозитории есть обученная модель, схема полей, код обучения и агрегированные результаты проверки. Примеры в интерфейсе и тестах составлены для демонстрации.

## Сторонние материалы

JSZip и шрифты сопровождаются исходными лицензиями в `dist/`. Палитра, шрифты и иллюстрация описаны в [DESIGN.md](../DESIGN.md). Открытая лицензия на код проекта и обученную модель пока не выбрана.
