# Разработка и история проекта

Проект разрабатывается совместно участником хакатона и ИИ-помощником Codex. Участник определяет продуктовый сценарий, обсуждает требования кейса, предоставляет данные и выбирает визуальное направление. ИИ-помощник помогает с анализом данных, реализацией, документацией и проверками. Это описание процесса, а не заявление о независимой клинической экспертизе.

## Что сделано до начала Git-истории

До создания репозитория были реализованы анализ предоставленного датасета, обучение моделей, ввод и импорт анализов, отчёты, русскоязычный дизайн и сценарий работы врача с памяткой пациенту. Эти этапы обсуждались и выполнялись в рабочем чате.

Локальная история Git начинается со снимка уже существующего MVP, затем фиксирует подготовку к GitHub. На GitHub сначала добавлен README, затем загружен проект через подключённый сервис GitHub: это отдельная история первоначальной загрузки. Предыдущие этапы не изображаются отдельными коммитами; даты не изменяются задним числом. Для дальнейшей работы с историей GitHub используйте свежий клон репозитория.

## Как продолжать работу

1. Создать ветку под конкретное изменение: `git switch -c feature/short-name`.
2. Внести изменение и выполнить `npm test`, затем `npm run build`.
3. Проверить изменённый сценарий в браузере; при изменениях модели отдельно пересчитать качество на отложенной выборке.
4. Посмотреть `git diff`, выбрать нужные файлы командой `git add`, сделать коммит с описанием реального изменения.
5. Отправить ветку в GitHub и открыть pull request для обсуждения.

Для защиты можно показать историю коммитов, изменения файлов, проверки в Actions и сценарий из [DEMO.md](../DEMO.md). История Git фиксирует версии проекта; сама по себе она не доказывает авторство каждой строки или медицинскую эффективность.

## Данные и воспроизведение

Исходные записи пациентов, бланки, словарь Excel и временные выгрузки не включены в репозиторий. Для повторного обучения нужен законно полученный исходный датасет и словарь организатора. В репозитории есть обученная модель, схема полей, код обучения и агрегированные результаты проверки. Примеры в интерфейсе и тестах составлены для демонстрации.

## Сторонние материалы

JSZip и шрифты сопровождаются исходными лицензиями в `dist/`. Иллюстрация создана с помощью ImageGen; её описание есть в [DESIGN.md](../DESIGN.md). Открытая лицензия на собственный код и обученную модель пока не выбрана; публикация репозитория сама по себе не задаёт такую лицензию.
