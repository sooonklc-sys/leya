# Обучение моделей

- `train.py` — подготовка признаков, разделение данных на обучение и тест, обучение Random Forest, оценка качества и экспорт моделей для браузера.
- `requirements.txt` — зависимости Python для повторного обучения.

Пропуски заполняются медианами внутри обучающего конвейера. Реализованы модели для основного ОАК и расширенного набора показателей: классификатор 12 состояний и отдельные бинарные модели дефицитов. Эти классы относятся к текущему прототипу; соответствие исходной постановке кейса описано в [DEMO.md](../DEMO.md).

Состав данных и ограничения: [описание данных](../docs/DATA.md), [карточка модели](../docs/MODEL_CARD.md). Метрики сохранены в [model-evaluation.json](../model-evaluation.json).

Исходные медицинские данные и результаты аудита с построчными значениями не предназначены для публикации в репозитории.
