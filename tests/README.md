# Автоматические проверки

- `core.test.mjs` — проверки расчётов и обработки входных значений.
- `demo.test.mjs` — проверка синтетических демонстрационных примеров.
- `pdf.test.mjs` — проверки импорта лабораторных результатов из PDF.
- `server.test.mjs` — проверки локального HTTP-сервера.

Запуск из корня проекта с Node.js 20 или новее:

```sh
npm test
```

Подробнее: [описание тестирования](../docs/TESTING.md). Эти проверки подтверждают поведение программы, но не заменяют независимую клиническую валидацию модели.
