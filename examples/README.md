# Учебные данные

`demo.csv` содержит три полностью синтетические строки без имён, идентификаторов и контактов. Это иллюстрации сценариев, а не записи обучающего датасета и не подтверждённые диагнозы.

| Запись | Сценарий | Что показать |
|---|---|---|
| 1 | Полный основной набор с дополнительными показателями | Расширенная модель, памятка врачу и пациенту |
| 2 | Hb выше порога и сниженный ферритин в учебном примере | Разделение оценки Hb и гипотез о дефицитах |
| 3 | Только основной ОАК, RDW отсутствует | Расчёт без RDW и ограничение выводов о причинах |

Файл используется в автоматическом тесте `tests/demo.test.mjs`. Для демонстрации в браузере выберите встроенные учебные примеры или перенесите числа вручную. Интерфейс принимает PDF, загрузка CSV/Excel удалена. Единицы описаны в `docs/DATA.md`. Не заменяйте этот набор данными пациентов для публичной демонстрации.
